# VersaChat 架构设计文档

## 概述

VersaChat 是一个多角色 AI 对话平台，支持多个 AI 角色在同一场景中进行对话。本文档描述了系统的核心架构设计。

## 核心模块说明

### 1. app.py - 主应用

**职责**：
- Streamlit 界面渲染
- 角色轮转调度
- 状态机管理
- 用户交互处理

**核心状态**：
- `IDLE` - 等待开始
- `RUNNING` - 对话进行中
- `PAUSED` - 已暂停

### 2. llm_backend.py - LLM 接口层

**设计模式**：工厂模式

```python
ModelInterface(model_type, model_name)
    └── 根据 model_type 创建对应的接口实例
        ├── DashScopeInterface
        ├── OpenAIInterface
        ├── AnthropicInterface
        └── OllamaInterface
```

**特性**：
- 统一的 `chat()` 接口
- 自动重试机制 (`@with_retry`)
- 消息格式化（区分 assistant/user/narrator）

### 3. context_manager.py - 上下文管理

**组件**：

| 类 | 职责 |
|---|-----|
| TokenEstimator | 估算文本 Token 数量 |
| ContextWindowManager | 智能截断历史消息 |
| RoleMemoryManager | 构建增强版 System Prompt |
| ConversationFlowController | 控制对话流程和重试 |

**Token 估算算法**：
```python
chinese_ratio = 中文字符数 / 总字符数
chars_per_token = 1.3 * chinese_ratio + 4 * (1 - chinese_ratio)
tokens = len(text) / chars_per_token
```

### 4. config_manager.py - 配置管理

**双层配置机制**：
1. **系统层**：`.env` 文件，管理员配置
2. **用户层**：加密存储，用户通过 UI 配置

**优先级**：用户配置 > 系统配置

**安全特性**：
- 使用 `cryptography` 库加密
- Salt 随机生成
- Key 派生使用 PBKDF2

### 5. session_manager.py - 会话管理

**功能**：
- 自动保存 (`autosave_session`)
- 会话加载 (`load_session`)
- 会话删除 (`delete_session`)
- 导出 Markdown/JSON

**存储格式**：
```json
{
  "id": "session_uuid",
  "name": "场景名称",
  "last_modified": "2024-01-07 12:00:00",
  "roles": [...],
  "chat_history": [...],
  "turn_index": 5,
  "round_count": 10
}
```

## 数据流

### 对话执行流程

```
1. 用户点击「开始」
   ↓
2. 状态切换为 RUNNING
   ↓
3. 进入调度循环
   ├── 流控制：等待适当延迟
   ├── 确定当前发言角色
   ├── 构建上下文（智能截断）
   ├── 构建增强 System Prompt
   ├── 调用 LLM（含重试）
   ├── 更新历史记录
   └── 自动保存
   ↓
4. 轮转到下一个角色
   ↓
5. 重复 3-4 直到暂停
```

### 消息格式化

```python
# 原始历史
[
  {"role": "narrator", "name": "旁白", "content": "..."},
  {"role": "assistant", "name": "苏格拉底", "content": "..."},
  {"role": "assistant", "name": "亚里士多德", "content": "..."}
]

# 格式化后（对于苏格拉底的视角）
[
  {"role": "system", "content": "<增强提示词>"},
  {"role": "user", "content": "[旁白/场景]: ..."},
  {"role": "assistant", "content": "..."},  # 自己之前的发言
  {"role": "user", "content": "[亚里士多德]: ..."}  # 其他角色
]
```

## 扩展点

### 添加新的 LLM 提供商

1. 继承 `BaseLLMInterface`
2. 实现 `chat()` 和 `test_connection()`
3. 在 `ModelInterface._create_interface()` 注册
4. 在 `config_manager` 添加配置支持

### 添加新的场景模板

1. 通过 UI「存为模板」功能
2. 或手动创建 JSON 文件到 `templates/` 目录

## 性能考虑

- **Token 估算**：O(n) 时间复杂度
- **上下文截断**：从后往前遍历，O(n)
- **会话保存**：异步不阻塞 UI
- **模型调用**：串行执行，支持重试
